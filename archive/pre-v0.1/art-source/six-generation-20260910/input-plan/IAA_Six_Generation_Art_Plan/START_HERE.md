# 开始阅读：IAA 六代美术资源生成计划包

本包是计划与委派文件，不包含新生成的六代图片、字体或已执行报告。未修改 GitHub 仓库。

先阅读 `IAA_六代美术资源生成计划书.md`；执行时总控读取 `tasks.json`，然后将 `agents/A0_委派卡.md` 与各角色卡派发。按代装配需求在 `generations/`。源证据见 `SOURCES.md` / `sources.json`。

文件夹可以放进仓库文档区或作为 Codex 附件，不要覆盖仓库根级 AGENTS.md。实际资源候选未来写入 `art-source/six-gen/`，本包不会提前创建或填充那些生产输出。

`reuse-inventory.json` 是60项既有资源的结构复用表（41项在当前构建白名单）；它不是全量PNG重新验收记录。`asset-candidates.json` 是39项基础+1项条件新增计划。所有任务和候选都是PLANNED。

`contracts/` 给出计划快照、真正的JSON Schema和三份带空值的示例。示例空值必须由实际测量填入；不得当成已经生成的资源或运行清单。Schema检查只检查结构，文件、alpha、SHA、参考可见性与视觉状态仍要实查。

阶段A只制作/验收资源候选与独立预览。阶段B运行接入单列，需要另行授权，不能自动发布或更改游戏规则。
