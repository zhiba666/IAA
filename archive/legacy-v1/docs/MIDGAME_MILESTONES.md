# 中期成长：余热接力、批量升级与换代接续

日期：2026-09-06。继续落实[调研计划](INCREMENTAL_UI_GAMEPLAY_RESEARCH_2026-09-06.md)的 P1 候选项，承接[生产档位与回归体验](PRODUCTION_MODES_ITERATION.md)。本轮聚焦已有主线的操作变化和具体等待段。

## 设计与实际行为

**多头机解锁批量升级。** 升级面板默认“单级”，可以切到“最多5级”。每条升级显示实际可购买级数、当前→最终等级、逐级价格合计和最终收益。钱只够2级就明确购买2级；接近Lv24时不越过上限。切换数量只更新展示，购买另需点击；重新打开面板回到单级，首页推荐和数字快捷键继续购买一级。

已备齐下一机器金币时，批量只花超出的余额；金币尚未攒齐时不预扣整笔未来资金。单级保留自由购买，界面明确区分。批量没有折扣，也不是自动计算的最优投资路线。按钮携带看到的起始等级、数量和总价；按住期间报价改变不会偷偷多买，旧报价重复提交不能再次扣款。广告报价或播放期间批量操作互斥。

原拟在自动流水线开放批量，但8条固定模拟路线到此时三条升级已全部Lv24，功能会失去作用。到多头机时，主动路线为18/18/18级，低频点击路线为15/19/18级，仍分别剩18和20级，因此根据结果提前到多头机。剩余级数并不代表当时能一次付得起5级。

**爆裂玉米Lv16＋多头机解锁余热接力。** 完美爆锅实际结算后，接下来10次点击各额外增加1能量；普通点击仍有原本的2能量，单次产量与售价不变。下一次完美爆锅刷新为10次，次数不叠加；普通爆锅不删除剩余次数，被动生产不消耗余热。已经获得的次数可随存档保存，离线不新赠次数，也不把余热换算成离线产量。

这项里程碑将“抓准火候”连接到“下一锅更快蓄能”，保留原有本锅额外20%和正常免费爆锅。生产按钮在原位置显示剩余次数和额外能量；不新建主屏卡片或领奖弹窗。手摇锅与电热锅阶段不提前灌输余热门槛，双缸机后再预告。

**换代面板连接有效投资。** 当订单条件已齐、金币不足，且现有常驻自动收入估算认为一次升级可缩短攒钱时间时，原换代主按钮位置显示“查看提速升级”。点击打开并高亮对应升级行，不直接花钱；购买仍需确认具体升级。已经具备换代条件时直接提供换代，不值得再升级时继续显示资金缺口。

这个估算仍是现有局部模型：不购买需缺口/常驻收入；购买后需(缺口+成本)/升级后常驻收入。它不包含玩家点击、免费爆锅、广告、未来升级和未领任务奖励，因此界面明确使用“按常驻收入估算”。

## 第10→11单的分析

使用真实核心方法从零经营，及时领取成长任务与订单，同一套边际收入回本策略购买升级，比较常规、赶单、高价和按目标切换。主动每秒2次点击；低频点击严格每5秒1次，但购买和领奖仍由每秒检查的脚本决定，不等同于每5秒才看一次游戏的真实玩家。未使用广告、离线或完美点火。

| 路线 | 第10→11单总时间 | 换代前资金受限、同时生产 | 换代后继续生产 |
| --- | ---: | ---: | ---: |
| 主动／常规 | 220秒 | 150秒 | 70秒 |
| 主动／按目标切档 | 203秒 | 131秒 | 72秒 |
| 低频点击／常规 | 347秒 | 248秒 | 99秒 |
| 低频点击／按目标切档 | 309秒 | 214秒 | 95秒 |

表中两段时间不重叠；攒钱期间也在推进第11单，不能把“等待金币”与“等待产量”重复相加。第9→10单常规路线为40/70秒，而第10→11单变为220/347秒，是明确的节奏变化。常规主动路线中最长122秒没有升级、换代、领任务或切档，低频点击路线为176秒。

从相同自然获得的第10单存档改为“停升级，只攒多头机”，8个反事实分支全部更慢，第11单延迟8～191秒。因此本轮保留订单目标与设备价格，把换代面板接到确实有助于攒钱的升级；不能从看到资金缺口直接推导出“应该停购”或“必须降价”。这也不证明现有等待已经让真实玩家满意。

原始数据和可复现工具：

- [midgame-analysis.json](../artifacts/midgame-analysis.json)
- [midgame-analysis.cjs](../tools/midgame-analysis.cjs)：包含阶段耗时、资金账、自然存档分支、设备到达时的升级等级及源码校验。
- [milestone-analysis.json](../artifacts/milestone-analysis.json)：余热的理想点火对照与相同状态下的批量操作核对。

所有模拟只用于比较已说明的策略和规则，不是玩家数据、留存结论、广告收益或全局最优解。批量升级减少操作，不据此承诺通关更快。

## 余热收益与批量操作对照

从自然经营得到的多头机存档分别运行600秒，固定设备、升级和档位，比较同样理想完美点火时启用与禁用余热。每秒2次点击、玉米Lv18的产量由25,733,086增至26,663,413，余热额外增产 **3.62%**，完美爆锅由30次增至33次。每5秒1次点击的自然到达状态只有玉米Lv15，尚未解锁余热，增产为0；自然生产2秒后支付2,561,400金币升到Lv16，再从相同状态对照，产量由17,339,004增至17,657,907，余热额外增产 **1.84%**，完美爆锅由8次增至9次。

实验采用0.05秒步长，控制器每锅都在完美窗口点火；以上比例只表示这组固定状态下的理想操作结果，不是普通玩家预期收益或完整路线提速。两组已解锁状态分别获得并消耗330/330、90/90次余热，发放后的10次余热也逐次通过存档读回核对。

三个升级方向分别从同一自然攒款状态克隆对照，5次逐级购买与1次批量购买的整个经济存档、产量和收益完全一致；这组购买操作由5次减为1次，减少80%。可用 [milestone-analysis.cjs](../tools/milestone-analysis.cjs) 重现，完整结果见上方数据文件。
