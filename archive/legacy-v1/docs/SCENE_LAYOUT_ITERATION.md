# 主场景布局改版 · 2026-09-06

根据本地试玩的三处批注，已完成金币浮层、目标合并和直接点击机器生产。

## 当前行为

- 金币余额与实时自动金币/秒固定显示在场景左上角；点击数值不会生产。
- 当前成长目标与下一步操作共用底部一张卡。场景右上角保留独立的主线订单，下面可查看机器和切换生产档位。
- 移除常驻的独立生产按钮。点击机器、机器下方空地或产量提示即可生产；保留新手 0/5 进度、实际产量反馈和余热次数。新手目标卡仍可按当前任务提供“继续生产”动作。
- 能量条与点火合并在场景底部，点火位置在解锁、禁用及已尝试状态下保持固定，且与生产区域分离。
- 钱包、机器与订单信息置于场景上方；六种机器按各自边界取景，保留摇杆、接料桶和后期传送带包装。
- 操作提示与爆锅提示共用反馈位置，操作提示优先，避免小屏出现文字遮挡。

430×932 视口下，主场景由 500px 增至 742px，高度增加 242px（48.4%）。该数值指场景卡，包含内部浮层与火候操作区，不代表机器本体增大相同比例。
