# 前 5 分钟体验打磨记录

日期：2026-09-06。范围为本轮已确认的首局指引、成长信息、关键反馈及本地验证；真机验收与软著办理继续暂停。

## 完成内容

- 首局提示展示点击进度、具体操作和所缺金币，突出对应按钮。首单提前达标时优先提示普通装车；先买自动升级、提前领单、重进游戏均按既有状态继续，不要求重做。
- 三类升级显示购买前后的点击份数、永久自动金币/秒或每份售价。预览与真实购买共用产能公式，自动收益明确排除临时增压。提示区显示下一机器的金币和订单缺口，达标后提供换代入口；蓝图和换代面板展示永久收益及点击产量变化。
- 四类激励在未开放或冷却期间禁用，显示剩余秒数；普通订单和离线领取位于可选广告之前。没有改变奖励资格、倍率或广告冷却规则。
- 点击机器即时响应；短时间内的连点浮字合并为实际合计产量。爆锅显示本次产量和售出金币，普通装车显示实际实收金额，换代显示永久自动收益前后值。浮字最多 8 个，粒子继续共用 180 个上限。
- 引导区只负责导航，购买仍使用升级按钮。弹层、提示与生产/购买区域没有新增重叠命中。存档结构和经济配置保持不变。

## 复核入口

```powershell
npm run build
node tools/experience-check.mjs
npm start
```

普通试玩：[本地游戏](http://127.0.0.1:4173/)。人工验证页使用 `/experience-check.html?mode=normal&width=390&height=844` 或 `/experience-check.html?mode=low&width=320&height=568`。需要两个新存档时，用不同本地端口启动服务；不要清除已有游戏存档。

QA 页的 `mode` 只标记路线并提供默认视口。它显示基线、最新状态、首次事件区间和错误记录，可手动下载全部采样；不自动操作游戏，不向外部上报，且不进入抖音包或玩家正常界面。
