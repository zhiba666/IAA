## 未上线小游戏完整真机链路

1. 在开放平台“开发设置 → 测试管理 → 添加设备”用实际试玩抖音号扫码加入测试环境。已添加的设备不重复添加。
2. 通过“开发者助手 → 在线客服”申请未上线小游戏侧边栏测试加白，由平台确认处理结果；下方已准备可核对的申请草稿，本次未发送。
3. 手机上进入抖音“我 → 更多 → 更多功能 → 开发者模式”，选择本游戏，开启“全入口打开指定版本小游戏”。具体入口以客户端实际界面为准。
4. 选择“扫码选择指定版本”，扫描当前 IDE 预览二维码；或选择已上传的 IDE 测试版本。本轮仅生成预览二维码，没有上传测试版本。
5. 从游戏内侧边栏入口跳转，再点侧边栏中的本游戏返回，检查是否保留原订单、升级和金币进度，并在引导页显示欢迎返回文字。此版没有复访奖励，不额外发放金币。

开发者模式及平台加白完成前，官方“方案 1”的 IDE 模拟器链路已经验证；“方案 2”指定场景 `021036` 的扫码测试只能验证场景启动识别，不能证明手机真实侧边栏可见或可返回。
