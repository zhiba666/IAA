## 最终提示词：基础组件

Use case: ui-mockup. Asset type: actual raster game UI artwork, isolated 2D UI assets for a portrait casual popcorn-factory management mobile game. NEW ARTWORK, NOT an edit of a scene or screenshot. Consistent very simple rounded mobile game art: warm cream opaque panel faces, dark desaturated teal readable Chinese lettering, medium teal secondary surfaces, muted golden-yellow primary action faces, small red accents only on popcorn paper cups. Flat solid-color materials, a single broad outline and at most a short 2-3 px darker offset edge for tactile depth. Economical reusable components, no realistic materials, no glass, no metal, no elaborate illustration, no fine texture, no bloom, no dramatic drop shadow. Typography: crisp friendly rounded Chinese sans-serif; all specified Chinese text exact and clearly legible. Front-facing orthographic 2D, no perspective. Genuine transparent alpha background, do NOT draw a checkerboard, colored backdrop, paper, poster, device frame, game environment, screenshot, artboard title, dimension marks, captions or annotation. Each asset has its own clean silhouette. Generous transparent separation; no overlaps, no connecting lines, no shared background plate. Keep all edges inside canvas. Only draw the asset art and in-product labels. Consistent radii, stroke weight, icons and spacing throughout.
