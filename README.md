## 立即试玩

需要 Node.js 18 或更新版本。在此目录运行：

```powershell
npm run build
npm start
```

打开 [本地试玩](http://127.0.0.1:4173)。服务只监听本机。也可直接打开 `web/index.html`，浏览器存储策略可能因 file 协议而不同，建议使用本地服务。

启动后先阅读健康游戏忠告，点击「开始经营」进入工厂；有待领离线收益时继续显示领取面板。点击机器或机器下方空地生产，点击场景左侧入口查看当前目标与推荐操作；新手默认展开，也可手动收起。金币余额与自动收益常显于场景左上角，场景右上角保留主线订单和档位入口；能量与点火位于场景底部，已移除独立生产按钮。设置位于「工厂」面板右上角。底部「升级」查看三类永久升级，「订单」直接装车领取，「任务」查看成长奖励，「工厂」查看换代、蓝图、品牌合作和涡轮增压。电脑支持空格生产、1/2/3 升级、O 查看订单、M 查看换代、Q 查看成长任务、B 查看品牌合作、P 查看生产档位、Escape 关闭面板或收起主页目标；启动忠告期间不能用快捷键跳过开工。进度属于当前浏览器和来源，不跨设备同步。

浏览器明确使用模拟激励：可以选择完整观看、中途关闭、加载失败；没有接入真实广告流量。激励前 90 秒不开启，激励之间无固定冷却，播放中仍拦截重复请求，普通成长始终可用。

完成第10单后，「订单」面板会显示分段交付与右上角「委托」入口，可选择补货或精品路线；完成20张主单并建成巨型爆米花塔后，从「工厂」进入竣工收藏。

## 抖音小游戏包

`npm run build` 生成 `build/douyin/`，包含 `game.js`、`game.json`、`project.config.json`、`config.js`、`game.bundle.js`。在抖音开发者工具中导入该目录进行联调。

需要联调时，在根目录创建已被 Git 忽略的 `config.local.json`，填写自己已开通的配置：

```json
{
  "appId": "你的 AppID",
  "rewardAdUnitId": "你的激励视频广告位 ID",
  "interstitialAdUnitId": "你的插屏广告位 ID",
  "analyticsEnabled": false
}
```

再次构建会读取此配置，写入发布目录；不要只修改生成目录里的配置，因为它会在下次构建时重新生成。抖音构建强制禁用模拟奖励。未填写 ID 时广告返回不可用，生产与普通结算继续工作。

## 文件分工

| 文件 | 用途 |
| --- | --- |
| `src/core.js` | 数值、生产、订单、成长任务、升级、离线、奖励与存档校验 |
| `src/renderer.js` | Canvas 场景、六种机器、界面、弹层、粒子和命中区域 |
| `src/interface.js` | 响应布局、当前目标、推荐升级、面板、分页和奖励预览 |
| `src/production-scene.js` | 六阶段机器、连续出料、爆锅粒子、装车与换代动画 |
| `src/experience.js` | 目标选择、首次事件、广告漏斗与只读体验导出 |
| `src/main.js` | 主循环、触摸、键盘、界面流程、自动保存与生命周期 |
| `src/platform.js` | 浏览器／抖音 API、广告、存储、生命周期、侧边栏检测与导航、埋点 |
| `src/audio.js` | 原创程序化音效和降级 |
