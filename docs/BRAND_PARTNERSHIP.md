# 品牌合作：永久广告收益

更新：2026-09-06。按用户要求加入永久广告收益，同时移除 120 秒广告冷却。

## 最终设计

新增“品牌合作”标签和详情面板（电脑 B）。完整观看一次激励视频就提升一级合作，永久基础产量增加 20 个百分点，最高 Lv.10、基础产量 3 倍。换代和重启保留，保存于当前设备的本地存档。

| 机器 | 已开放合作等级 | 该阶段最大永久产量加成 |
| --- | ---: | ---: |
| 手摇锅 | 尚未开放 | 0% |
| 电热锅 | Lv.1–2 | +40% |
| 双缸机 | 至 Lv.4 | +80% |
| 多头机 | 至 Lv.6 | +120% |
| 自动流水线 | 至 Lv.8 | +160% |
| 巨型爆米花塔 | 至 Lv.10 | +200% |

每级奖励独立兑现，不需要攒够多次观看才发奖。详情和广告确认都展示当前/下级百分比、点击产量与永久自动金币/秒。达到阶段上限时说明下一次换代再开放两级，满级后隐藏可领取资格。

计算方式：原点击产量、原永久自动产量分别乘以 1 + 合作等级 × 0.2。免费爆锅按加成后的点击和自动产能计算，避免重复乘倍率。每份售价保持原值，因此销售收入随产量增长。临时涡轮仍只让在线自动生产变为 3 倍，可以与永久产量加成同时生效。

之后产生的离线产量与金币也享受加成；已经生成的待领离线包保持原先金额，不因观看广告而追溯重算。订单累计产量更快达标，但订单结算和成长任务的固定金币奖励本身不额外放大。

本次未增加“必须看广告才能换代”的标志或抬高免费路线成本。永久收益通过明显加速成长吸引玩家主动选择；免费升级、装车、换代仍完整可达。

## 120 秒冷却移除范围

- 五类激励（增压、订单、赞助、离线、品牌合作）没有两次播放之间的固定冷却。成功、取消或失败后，可再次主动选择符合资格的奖励。
- 保留首次在线经营 90 秒的开放条件，以及订单达标、离线包存在、品牌阶段容量等各自资格。
- 一次只处理一条广告；加载/播放未结束时阻挡重复点击，结束后恢复。关闭面板不会发放奖励，只有明确的完整观看回调才能永久升级。
- 插屏的原 120 秒产品间隔也移除，但两次实际插屏仍间隔至少 60 秒，激励结束后至少 60 秒才可插屏；保留启动保护、前 20 分钟最多两次和失败请求 30 秒退避。这些限制不阻挡玩家连续选择激励视频。

已于 2026-09-06 核对[抖音小游戏行为规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/game-rule)：插屏之间及激励后的插屏要求 60 秒间隔。真实广告仍取决于平台填充与配置，没有接入虚构广告位。

## 持久化和异常处理

沿用 version 1，新加 brandLevel 字段；旧存档默认 Lv.0，已获得的任务、机器和升级保留。恢复时校验等级为整数且不超过机器已开放容量；先恢复合作等级，再计算新的离线收益。旧广告观看记录不追溯转换为合作等级。

品牌报价保存当时等级。结算前重新核对该等级、阶段容量及领取 ID，重复回调不能重复升级；领奖成功后立即保存。主程序启动会取消没有完成回调凭据的历史请求。移除冷却后，无广告历史不会被误判为“刚看过广告”的升级归因。

广告失败或超时后解绑并隔离旧 SDK 实例，尝试销毁；异步销毁完成前安全返回不可用，销毁异常也不允许复用受污染的实例。正常完整观看或中途关闭后继续复用，不增加固定激励冷却。专项回归通过真实旧实例 emit(close) 验证迟到事件不会给下一次请求发奖，并覆盖异步销毁、销毁异常及恢复。广告播放期间仍暂停游戏生产计时，不将观看时长重复算成离线收益。

## 固定策略数值回归

每秒点击 2 次、选择永久收益回本时间最短的升级或换代、达标后装车；每条广告计 30 秒，观看期间暂停游戏。没有人为增加免费成本。下表不领取成长任务，以便与此前基线直接对照；领取全部任务的广告路线另有测试覆盖。

| 路线 | 游戏时间 | 广告观看 | 总时长 |
| --- | ---: | ---: | ---: |
| 主动免费 | 58分40秒 | 0 | 58分40秒 |
| 仅永久广告 | 24分20秒 | 10次 / 5分钟 | 29分20秒 |
| 临时收益高广告 | 28分20秒 | 34次 / 17分钟 | 45分20秒 |
| 永久与临时综合 | 12分46秒 | 33次 / 16分30秒 | 29分16秒 |

仅永久路线计入观看后加速 50%，终局相同机器/升级下永久自动收益为免费路线的 3 倍。免费每次换代的时刻也保持原基线。纯放置免费路线仍为 103分42秒；离线回归路线另计 8 小时离开时间。综合观看更多广告不保证按比例更快，表中数据按真实模拟结果保留。

这些是确定性策略模拟，不代表真实玩家耗时、留存或广告收入；没有计入阅读、点击选择、无填充或人工犹豫。原始配置及六条逐步路线见[数值结果](../artifacts/permanent-balance.json)。运行 node tests/balance.cjs 可复现。
