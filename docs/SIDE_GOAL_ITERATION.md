# 标题移除与侧边目标 · 2026-09-06

根据第二轮试玩批注，经营页移除顶部标题和底部目标卡，场景覆盖安全内容区内的大部分高度。

## 当前操作

- 游戏名称保留在启动页。设置入口位于「工厂」面板右上角。
- 左侧紧凑入口显示「下一步」「可领奖」「可装车」或「可换代」。点击仅展开详情，不直接升级或领奖。
- 展开后显示目标、下一步操作、收益与资金缺口；保留原有目标入口和推荐按钮。
- 新手教程尚未结束时默认展开，教程结束后自动收起。玩家也可手动收起或展开；手动选择在本次运行内保持，不改存档结构。
- Escape 先关闭弹层；主页目标展开时则收起目标。
- 展开目标不改变场景宽度，机器在剩余可见区域重新取景。生产区域与面板、钱包、点火、订单和底部导航均不重叠。
- 完整目标和推荐只有展开可见时才记录曝光，避免将收起的详情计为已展示。

主场景由 `y=53..高度−137` 扩展为 `y=8..高度−60`，比上一版再增加 122px 高度。549×697 浏览器中游戏按现有规则居中使用 480px 逻辑宽度；场景高度由 507px 增为 629px。430×932 下场景高度为 864px。这些是场景卡尺寸，包含浮层和火候操作区。
