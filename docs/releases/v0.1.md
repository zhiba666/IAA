# v0.1 正式版

日期：2026-09-10。Git 标签：`v0.1`。包版本：`0.1.0`。

将当前两段搬运与分段自动化玩法、六代工厂美术接入统一记录为 v0.1 正式版。此前软件标识 `2.0.0` 和“1.5”方案名称属于研发阶段命名；本次统一软件版本，不改变 `v15` 玩法标识、schema 4 正式存档或旧档迁移规则。

本版包含 84 张运行 PNG、18 组代际工位装配、实际生产驱动的包装与动效、图片加载重试，以及既有设备、物流、自动试运行与扩建玩法。Web 与抖音包来自同一构建入口。

## 归档与保留

- 共归档 637 个文件，逐文件校验 SHA-256 与字节数一致；上传归档 303 个，本地保留 334 个。详见 [归档索引](../../archive/README.md)和 [完整映射](../../archive/pre-v0.1/manifest.json)。
- 已归档旧方案、未实施的 v1.5.1 体验设计、batch-0/batch-1 制作记录、六代原始计划、旧验收与被替代截图。构建读取两份归档装配 JSON，当前运行 PNG 保留活动路径。
- 按用户确认保留 `art-source/six-gen/qa/`、`reports/` 静态预览和展示依赖；其余非本地资料随 Git 上传。重复的 84.35 MiB 美术交付 ZIP 仅本地保留，并由 `.gitignore` 排除。
