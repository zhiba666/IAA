# 当前开发重心

更新：2026-09-10。当前正式版本为 **v0.1**，包版本为 `0.1.0`。版本说明见 [v0.1 正式版](releases/v0.1.md)，运行与构建命令见 [README](../README.md)。

当前发布验证以 [v0.1 记录](releases/v0.1.md)为准。以前的测试数量和截图只说明当时构建的结果。真人新手观察、抖音 IDE 和真机验收尚未完成，GitHub 版本发布不代表抖音平台上线。
