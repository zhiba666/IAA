# 当前开发重心

更新：2026-09-09。本轮为**首代新美术正式接入与画面验收**，继续使用当前 IAA 生产核心。正式运行入口见 [README](../README.md)，本次构建、测试、截图、短录屏、资源加载检查与最终验收边界统一见 [首代画面验收记录](GEN1_VISUAL_ACCEPTANCE_2026-09-09.md)。代码接入与画面验收分别记录，不以资源存在或测试通过替代视觉结论。

## 本轮实现范围

- 正式 `web/index.html` / `src/main.js` 入口使用 `src/first-generation-scene.js` 装配首代三工位、两仓、输送路径；`src/interface.js` 接入主 HUD、工位改造区和购买后的折叠反馈。独立美术预览页不作为正式接入证据。
- `src/art-assets.js` 负责浏览器 `Image` 与抖音 `tt.createImage` 加载，主 HUD 显示装配中或加载失败状态。`src/art-layout.js` 统一原图、装配及屏幕坐标，图片、裁切、工作头、端口和命中区使用同一变换；UI 底板使用九宫格，文案和数值运行时绘制。
- `tools/art-build.mjs` 从现有 `assets/art` 清单与 `art-source` 装配数据生成 `src/art-manifest.js`。当前运行清单为 41 个 PNG，复制到 `web/assets/art/` 与 `build/douyin/assets/art/`，检查 PNG 尺寸和逐文件 SHA-256。体积及复制结果见 [运行资源报告](../output/gen1-art-runtime/resource-report.md)。整屏参考图、源图和未引用的高代包装资源不进入运行清单。
- 加工表现只读取真实 `jobs`、`buffers` 和事件：缺料停机，堵塞保留完成品，升级保留旧批次的 `amount`。出货动画仅展示已结算事件结果。`src/core.js` 与 `src/factory-rules.js` 本轮未改，不新增库存、金币或玩法。

## 当前验收重点

在正式入口核验 390×844 和 320×524，包括安全区、改造区展开/折叠、首次装杯升级、缺料和满仓。布局先保留整条产线与可辨认的机器、产品，再压缩辅助说明；触控区至少 44×44。极短可用空间使用两行比较，辅助改造说明可切到“详情”，不省略设备能力、预计整线出货的单位、价格或购买条件。

实际运行媒体、当前测试数量、构建/预检结果、加载清单和未解决问题以 [本次验收记录](GEN1_VISUAL_ACCEPTANCE_2026-09-09.md) 为准。真实阻塞质量的美术缺口按“具体文件或部件、影响场景、代码能否解决、最小补图需求”记录；不使用旧机器轮廓、变形拉伸或整机缩小复制掩盖缺口。
