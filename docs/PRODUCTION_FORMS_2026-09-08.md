# 产出形态与换代反馈

用户方向：成长通过产出的视觉单位和组织方式体现，让每次换代带来明显的新体验。

## 六代变化

| 设备 | 视觉单位 | 组织与动作 |
| --- | --- | --- |
| 手摇锅 | 散粒 | 单粒爆开，落入接料桶 |
| 电热锅 | 满杯 | 装满一杯，再整杯送出 |
| 双缸机 | 双杯组 | 双路交替接料，合并成组 |
| 多头机 | 六杯整托 | 六杯成型，整托送出 |
| 自动流水线 | 封装箱 | 装箱、合盖、封箱，再进入出货带 |
| 巨型爆米花塔 | 整垛货 | 逐层码齐，固定后整垛发运 |

`PRODUCTION_FORMS` 为场景、换代页、蓝图和提示提供一致名称。成品是批量生产的视觉表达；实际产量、金币、订单和存档继续由原有 Game 结算。

## 换代与连续生产

旧机器在前 0.28 秒收拢退场，新设备随后落位，0.8 秒启动首批重点成品。主换代效果持续 2.8 秒，提示显示 3.2 秒可见时间，给出新形态和真实永久自动收益倍率。横幅临时使用目标区域，机器完整位于其下方，结束后恢复目标展开偏好。独立安装音效覆盖浏览器和抖音包，震动遵循原设置。广告播放期间暂停场景计时，返回后继续；同期最新一份爆锅奖励在换代提示后显示。

下一批等待上一批移开，避免双杯、整托和货垛互相覆盖。重点成品单独展示，点击仍即时反馈。自动生产只发视觉批次，粒子不随经济数量增多：点击固定 2 粒（手摇锅 3 粒），爆锅固定 18 粒，完美爆锅额外固定 8 个星芒，换代不喷粒子。粒子硬上限 72，视觉单位硬上限 8，正常排布进一步限制在场批次。

出货节拍按真实生产量和经过时间积累，成功派发后才扣除额度，保留有界余量。无生产不派发，长暂停清除积压。升级继续改变机器转动、配方和包装细节。
