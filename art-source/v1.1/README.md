地板不是经认证的无缝纹理：请用一张等比覆盖视口，不进行重复平铺，也不要与旧 `factory_room` 的对角砖缝硬拼。新地板与墙角组合可作为原整体房间背景的替代背景方案；原资源未覆盖。

## 生成方式和记录

均使用内置 `image_gen.imagegen`，未使用 CLI/API fallback。源图保存原始尺寸。导出仅采用机械裁切、等比缩小与已目检的 PNG 压缩；没有把文字、金额、数量、等级烘焙进素材。

- 手势：[精确提示词](hand/prompts/ui_gesture_hand.txt)、[来源](hand/provenance.json)、[导出记录](hand/ui_gesture_hand.export.json)、[三底与小尺寸检查](hand/previews/hand-three-backgrounds-128-32-40.png)
- 地板：[精确提示词](floor/prompt.txt)、[来源与导出记录](floor/export.json)
- 墙角：[最终提示词](wall/prompt.txt)、[全部尝试](wall/prompts.jsonl)、[来源](wall/provenance.json)、[导出记录](wall/export.json)、[三底检查](wall/previews/wall-three-backgrounds.png)

工具未返回的 model/seed 不作推测，保留 unavailable 记录。各子目录包含可复现机械导出的 Node/Sharp 脚本。

## 运行接入与验证

全屏场景、HUD、居中模态、仅拖拽状态机和两段手势教学现已接入正式代码。手势指尖、真实数量、入口高亮与核心预留／提交／取消结果绑定；设备、物流、扩建窗口使用独立报价及模态输入层。

正式构建保留原 84 张与新增 3 张独立合同的来源、尺寸、SHA 和预算保护，由构建器生成清单及平台副本。正式玩法与验证命令见 [README](../../README.md)。
