# 包装装配校对

2026-09-09。`assembly-preview.png` 展示空托、双杯、空箱、四杯、封箱五种静态状态。`contact-sheet.png` 展示本组 11 个独立源件的导出外观。

装配复用首批红白空杯与填充层；卡槽使用两组独立锚点。托盘前挡沿由同一托盘图的局部重复层遮挡杯底，下方完整托盘始终保留。

箱体按后壳、后排杯、两侧杯、前排杯、前墙、箱盖顺序叠放。箱体前墙比后墙略低，保留现有源图的形状；盖沿在封箱状态遮住接合处。仅杯内容层使用装配裁切，未裁掉容器外墙或改变素材 PNG。

已目检：两杯落于独立卡槽；四杯按菱形排列且杯底被前墙遮住；空箱底面完整；封箱盖体与后壳对齐。所有部件等比缩放，脚本对每个 image 矩形与原图比例进行检查。

`assembly.json` 包含部件层级与矩形、槽位矩形与锚点、输入/输出点及裁切多边形。`assembly.svg` 为内嵌 PNG 的独立可编辑层组合。

复现：`node art-source/batch-1/core/build-assembly.cjs`。若项目未安装 Sharp，可将可用 `sharp` 模块目录作为第一个参数，脚本会同时输出两张校对 PNG。
