# 批次 0 · 美术样板规范

日期：2026-09-09。当前仅制作美术，不接游戏，不锁定最终运行布局。

## 视角与光照

- 机器、输送、容器：固定俯视的正交等距方向，地面两轴约为 `(1, 0.55)`、`(-1, 0.55)`；不在不同状态中旋转镜头。
- 光源统一左上方；青绿为机器主色、灰蓝为钢材，黄色只用于少量功能点与产品。
- 保持宽机壳、简化圆角及大色块，不继续增加旧式铜锅、齿轮堆叠或复杂纹理。
- 四张已选参考是唯一美术方向依据。旧版截图、旧代码外形不作为本批制作参考。

## 配色与产品比例

| 用途 | 样板色 | 规则 |
| --- | --- | --- |
| 机器主面 | `#219da5` | 阴面采用深青绿，不靠更换整套代际颜色表示成长 |
| 钢材 | `#555f69` | 低于产品对比，前挡板可独立遮挡 |
| 红白杯 | `#ed4435` / 奶白 | 竖条纹，空杯与内容分开 |
| 爆米花 | `#f4c64e` | 两粒轮廓与小堆复用，少量库存仍可辨识 |
| UI 面板 | `#f5efe0` | 青绿边框；金币 HUD 深青绿；主按钮金黄 |

装杯机共享装配画布为 **448×640**。杯体为 **104×128**，在装杯机内采用宽 92、高约 113 的比例。喷头独立，填充层在杯口裁切后升起；前挡板最后叠放。尺寸、锚点、输入/输出点和裁切多边形以 [assembly.json](assembly.json) 为准。

## 分层与 UI

机器顺序：机体 → 喷头 → 空杯/填充 → 前挡板。仓体顺序：后壳 → 裁切后的代表性产品 → 前挡板。两向输送带的产品在带面之上、近侧挡板之后。

UI 六张纹理均为 **384×138 RGBA**，九宫格四边各 **32 px**。源图无文字、数字、图标或金额。预览中的文字与状态描边单独叠加；常态/按下/禁用/选中通过同一底板组合示意。正文建议 12–14、主要数值 20–26、按钮 12–14 逻辑像素，字重 500–800，中文行高约 1.4 倍，数字使用等宽数字特性（环境支持时）。不增加字体文件。

## 导出与范围

PNG 从 5 张生成源中按连通对象分离，保留主体原始 alpha 与边缘两像素邻域，再等比缩小；大范围透明残留不带入单件。生成原图、提示词、切图种子与裁切记录均保留，可重复导出。`assembly.svg` 是可编辑的独立层组合源；它引用/内嵌栅格层，不是 3D 网格或可逐顶点编辑的矢量机器。

主校对视口仍为 390×844 与 320×524；本次先完成独立部件与静态装配校对，三工位两仓的整屏构图、真实点击区域和游戏状态绑定留到后续获授权的接入阶段。当前 19 张 PNG 不代表 A01–F01、六代成长或整批 P0 已完成。
